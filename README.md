# 🎮 Arcade Game Shop

A beginner Python project that simulates a simple arcade gaming shop checkout system.

## 📌 About the Project

Arcade Game Shop is a Python program where customers can choose gaming accessories, select quantities, and pay for their purchases.

The program calculates the total price, applies membership discounts, adds VAT (20%), and handles both cash and credit card payments.

## 🛒 Available Products

| Product | Price |
|---|---:|
| Game Controller | 250 DH |
| Gaming Headset | 180 DH |
| Gaming Mouse | 120 DH |

## ✨ Features

- Product selection
- Quantity selection and validation
- Shopping cart
- Automatic total calculation
- Membership discount (20 DH)
- VAT calculation (20%)
- Credit card payment with password verification
- Cash payment and change calculation
- Multiple cash payments
- Input validation

## 🛠️ Technologies Used

- Python 3
- Visual Studio Code

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Run the Python file.

## 🎯 Project Goal

This project was created to practice Python fundamentals, including variables, input/output, conditional statements (`if`, `elif`, `else`), loops (`while`), lists, and basic calculations.
